ORGCONNECT — GITHUB PAGES SETUP

1. Create a GitHub repository (example: orgconnect).
2. Upload ALL contents of this folder to the repository root.
3. In GitHub, open Settings > Pages.
4. Under Build and deployment, set Source to "GitHub Actions".
5. Open the Actions tab and wait for "Deploy OrgConnect to GitHub Pages" to finish with a green check.
6. Your site will be available at https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

- Vite base set to './'
